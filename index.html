📝 Für HashDB einreichen (Pull Request)

Neue Einträge kommen nur per Pull Request (oder Issue) ins Repo. Hier kannst du den fertigen JSON-Inhalt + Dateiname generieren.

So einreichen (Repo danltech/hashdb1):
1. Fork von github.com/danltech/hashdb1
2. Neue Datei: entries/xxxxxxxx.json
3. JSON einfügen → Pull Request öffnen
4. Ein Workflow merged gültige PRs (max. 1 pro Lauf) und baut index.json neu.
Manueller Trigger: Actions → „Process HashDB PRs“ → Run workflow
Alternativ: Issue mit dem JSON und Titel „HashDB-Eintrag: <id>“.

🔗 Embeddable Script

Lade browserhasher.js ein. Es schreibt eine Warnung in die Konsole und stellt window.DanlTechBrowserHasher bereit.

<script src="https://brwsrhash.danltech.xyz/browserhasher.js"></script> <script> DanlTechBrowserHasher.getHash().then(result => { console.log("Gesamt-Hash:", result.hash); console.log("Komponenten:", result.components); }); </script>
