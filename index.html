🧩 Embeddable Script

Lade browserhasher.js auf deiner Seite ein. Es schreibt eine starke Warnung in die Konsole und stellt window.DanlTechBrowserHasher bereit.

<script src="https://brwsrhash.danltech.xyz/browserhasher.js"></script> <script> DanlTechBrowserHasher.getHash().then(result => { console.log("Hash:", result.hash); // result.signals enthält alle Rohdaten }); </script>

📚 HashDB-Idee (separates Repo)

Für eine öffentliche Sammlung von Hashes kannst du ein separates Repository anlegen (z. B. danltech/browserhasher-hashdb). Nutzer können dort per Pull-Request ihren Hash + optionalen Kommentar einreichen. Die Seite hier speichert nichts serverseitig – alles läuft lokal im Browser.
